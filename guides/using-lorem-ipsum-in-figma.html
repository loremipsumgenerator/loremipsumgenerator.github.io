Using Lorem Ipsum in Figma

Shortcuts, plugins and best practices for placeholder text in Figma, from quick fills to realistic content.

The quick way to fill a text layer

Figma has no built-in lorem ipsum button, but filling a text layer is fast: select the layer, paste generated text from a tool like this site, and adjust the length to fit. For repeated elements such as cards and list items, fill one, duplicate it, and vary the lengths slightly so the design does not look cloned. A small variation in paragraph length makes a grid of cards look far more realistic than identical blocks.

Plugins that generate filler

Several Figma plugins generate lorem ipsum directly inside a text layer, and others generate realistic content such as names, dates and product descriptions. Content plugins are often better than plain Latin, because they produce realistic data that tests the design properly: a long name, a short name, a price with decimals. Try a content generator for data-heavy screens and keep classic lorem ipsum for body copy, where the exact words matter less.

Auto layout and placeholder lengths

Figma's auto layout makes placeholder text powerful, because frames resize as the text changes. Test your components with three lengths: the shortest realistic content, the average, and the longest. If a card breaks with the longest text, fix the component now, before development. Set minimum and maximum sizes on text layers so extreme content degrades gracefully instead of breaking the layout.

Sharing mockups with clients

When you share a Figma link with a client, add a short note explaining that the text is a placeholder. Clients who open a Figma file without context often read the lorem ipsum and worry that the site will be in Latin. A cover page in the file, or a comment on the first frame, prevents that confusion. For important reviews, consider replacing the most visible placeholder with draft copy so the client sees the design with realistic words.

From Figma to development

Before handover, replace placeholder text in the Figma file with real copy or with content specifications attached as comments. Developers who receive a file full of lorem ipsum have to guess what the real content will be, and that guessing causes layout bugs. Use Figma's dev mode to attach notes about each text block: the field name, the expected length, and an example of real content.

Figma variables and content

Figma's variables feature can make placeholder testing more systematic: store several lengths of filler as variables and swap them to see how a component behaves with short, medium and long content. This is faster than pasting text by hand each time, and it keeps the test consistent across the team. Combine variables with auto layout and you can test a whole page at three content lengths in minutes, which is a powerful way to find fragile components before they reach development.

Frequently asked questions

Does Figma have a built-in lorem ipsum generator?

No. You paste generated text in, or use a plugin that fills text layers with placeholder or realistic content.

Which Figma plugins are best for filler text?

Content-generator plugins that produce realistic names, dates and descriptions are often more useful than plain Latin for data-heavy screens.

How do I test long text in Figma?

Use auto layout, fill the component with the longest realistic content, and check that it resizes gracefully without breaking.

Can Figma variables hold placeholder text?

Yes. Store different lengths of filler as string variables and swap them to test how components behave with short and long content.
